Vice Cover Studio turns any photo into a GTA 6-style multi-panel cover: pick a layout, grade it Sunset, Neon, Noir or Palm, drag each photo into place, set the caption, and export a print-ready PNG.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, and no network needed while it runs.
